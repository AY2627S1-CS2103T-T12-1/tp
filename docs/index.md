**HireBase is a desktop app for tech recruiters to manage high-volume candidate pipelines.** It is optimized for use via a Command Line Interface (CLI) while still having the benefits of a Graphical User Interface (GUI). With HireBase, you can track candidates, update their interview stages, keep local job openings, and manage interview events in a calendar.

* If you are interested in using HireBase, head over to the [_Quick Start_ section of the **User Guide**](UserGuide.html#quick-start).
* If you are interested in developing HireBase, the [**Developer Guide**](DeveloperGuide.html) is a good place to start.
